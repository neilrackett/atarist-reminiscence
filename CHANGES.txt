* release 0.5.6-atarist.n

	Atari ST / STE / Mega STE port by Neil Rackett, based on 0.5.6
	with Gregory Montoir's permission. Atari-only code is not	listed;
	these are the core-engine changes every build gets.

	- Amiga title screen: Start / Options / Quit, with the levels under
	  Start and Skill under Options (Expert was unreachable). Lines
	  redraw only when they change, with a one-pixel drop shadow.
	- menus ignore the key that reached them: Return skipping the
	  intro no longer started a game, nor did skipping a death scene
	  answer the continue prompt.
	- cutscenes ignore keys pressed while loading or in their first
	  second, and start with a black palette buffer rather than the
	  previous scene's colours.
	- a SystemStub::rumble() hook, called when Conrad takes a hit
	  (does nothing unless a platform implements it).
	- the previous level's .SPC data is freed instead of leaked.
	- builds without zlib (plain save files) or an Ogg decoder.
	- SDL: RS_DUMP=<dir> saves every 25th frame as a BMP.

	Speed only, output identical:
	- Bytekiller reads bits through a reverse table, not a call per bit.
	- AMIGA_planar_mask reads each plane byte once instead of a multiply
	  per plane per pixel: 5.5s -> 1.7s a room at 8MHz.
	- divides and 32-bit multiplies out of the per-frame paths: piege
	  and collision grid bands, pge_collideTestByNumber,
	  pge_op_isInRandomRange and markBlockAsDirty.
	- READ_BE/LE helpers always inlined; hot resource reads skip the
	  function pointer, and findBankData remembers its last hit.
